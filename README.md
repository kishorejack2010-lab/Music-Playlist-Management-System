# Music-Playlist-Management-System
A Python-based Music Playlist Management System using Binary Search Tree (BST), Linked List, and Queue data structures for efficient song storage, searching, updating, deletion, dynamic playlist management, and recently played song tracking.
# 🎵 Music Playlist Management System Using Data Structures

## 📌 Abstract

The Music Playlist Management System is a comprehensive application designed to efficiently organize, search, and manage a large collection of songs. It uses a Binary Search Tree (BST) for efficient song storage and retrieval based on attributes such as song name and genre.

A Linked List is used to dynamically manage playlists, allowing efficient insertion and deletion of songs. A Queue follows the First In First Out (FIFO) principle to maintain recently played songs and track playback history.

The system provides features to add, search, update, and delete songs. Exception handling mechanisms are incorporated to manage runtime errors and improve application stability. The user interface is designed to provide an intuitive and user-friendly experience.

This project demonstrates the practical application of data structures in solving real-world problems through efficient data organization and retrieval.

## 🛠️ Data Structures Used

### 1. Binary Search Tree (BST)
- Stores and organizes songs.
- Supports efficient searching and retrieval.
- Helps search songs based on song name and genre.

### 2. Linked List
- Manages the playlist dynamically.
- Supports insertion and deletion of songs.

### 3. Queue
- Maintains recently played songs.
- Follows the FIFO (First In First Out) principle.
- Helps track playback history.
